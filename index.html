01

상세페이지 상시 분석 도구

스크롤·클릭 분석

배경

상세페이지를 개선하려면 방문자가 어디까지 읽고 무엇에 반응하는지 알아야 하지만, 행동 데이터는 쿼리 없이는 확인하기 어려웠다.

주요 기능

  • 과정·기간·유입경로별 스크롤 도달률과 클릭 순위 조회
  • 두 조건(기수 간, 유입경로 간) 나란히 비교
  • 페이지 구성 위에 스크롤·클릭 분포 시각화

활용

콘텐츠별 반응을 보고 상세페이지 개선 가설을 세우는 데 쓴다.

02

지원서 데이터 상시 분석 도구

지원자 특성 · 자기소개서 분석

배경

지원자 특성과 지원서 작성 행동을 보려면 매번 데이터를 내려받아 가공해야 했고, 자기소개서는 양이 많아 꾸준히 읽고 활용하기 어려웠다.

주요 기능

  • 연령·전공·현재 상태 등 지원자 특성 집계
  • 지원완료까지 걸린 시간과 지원 시간대 분석
  • 자기소개서를 지원 계기·기대 내용별로 분류하고, 새로 쓰이거나 바뀐 내용만 다시 분류

활용

유입 타겟이 핵심 타겟과 맞는지 확인하고, 자기소개서에 드러난 고민을 소재·메시지 아이디어로 쓴다.
